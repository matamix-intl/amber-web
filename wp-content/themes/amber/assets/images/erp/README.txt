Amber ERP hero images
=====================

The ERP hero (template-parts/erp/amber-erp-page.php) loads five images from THIS
folder. Save your files here with these EXACT names:

  dashboard.webp    -> the main ERP dashboard screenshot (large, ~1200px wide)
  atwork.png        -> "At Work" floating stat badge
  productive.png    -> "Productive" floating stat badge
  clockin.png       -> "Clock In" floating stat badge
  clockout.png      -> "Clock Out" floating stat badge

These mirror the reference (Desklog) images:
  Automated-Time-Tracking_img_.webp  -> dashboard.webp
  atwork-img.png                     -> atwork.png
  productive-img.png                 -> productive.png
  clockin-img.png                    -> clockin.png
  clockout-img.png                   -> clockout.png

desklog.io is not reachable from this machine, so the files must be added
manually. Once they exist, hard-refresh the page (Ctrl+F5) to see them.
